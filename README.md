# CS-PROUD-recon_dce
Reconstruction of PROUD DCE datasets, originally optimized for pancreatic DCE.
Options for reconstructions include:
- 4D (respiratory-resolved)
- DCE with given time frame lengths
- DCE with respiratory correction
- 4 phase DCE reconstruction (with varying lengths)
- t1 with respiratory correction
![image](https://user-images.githubusercontent.com/35814088/160131380-4a826a80-2f8c-4157-978e-2919656a4c72.png)


For each variation, run the 'define_profile...' script to select reconstruction parameters and raw data location.
